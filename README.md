# 🛡️ ThreatAtlas - Cybersecurity Threat Intelligence Dashboard

An interactive **Power BI dashboard** built to analyze over **1 million login events**, identify attack trends, visualize global cyber threats, and monitor suspicious login activities through rich interactive visualizations.

The dashboard transforms raw authentication logs into actionable security insights for SOC analysts, cybersecurity professionals, and decision-makers.

# 📌 Project Overview

This project demonstrates how Power BI can be used to convert massive authentication log datasets into an interactive cybersecurity monitoring platform.

The dashboard enables users to:

- Monitor worldwide attack activity
- Analyze attack success rates
- Track login attempts over time
- Identify vulnerable countries
- Compare attack patterns across months
- Detect suspicious login behaviour
- Explore attack data using interactive filters

---

# 📈 Key Insights

Some observations from the dashboard include:

- Over **1 million login events** were analyzed.
- Multiple countries consistently exhibited elevated attack activity.
- Mobile devices accounted for significantly more attack sessions than tablets.
- Certain months experienced noticeable attack spikes.
- Several regions maintained unusually high attack success rates.
- Interactive filtering allows detailed investigation by country, month, and device.
